# Checkpoint 4

## Что реализовано

- Пагинация, фильтрация и сортировка списка ресурсов
- Поиск свободных залов на заданную дату и время
- Расписание ресурса на день / неделю
- Отзывы с оценкой (только после завершённого бронирования)
- Средний рейтинг ресурса в ответе API

---

## Запуск проекта

```bash
php artisan migrate:fresh --seed
php artisan serve
```

Сидер `ReviewSeeder` создаёт тестовые данные:

- 2 бронирования **с отзывами** (resource_id=1, user_id=2)
- 1 бронирование **без отзыва** (resource_id=3, user_id=2) — для тестов 11/12

## API эндпоинты

### Публичные

| Метод | URL                            | Описание                                      |
| ----- | ------------------------------ | --------------------------------------------- |
| GET   | `/api/resources`               | Список залов (пагинация, фильтры, сортировка) |
| GET   | `/api/resources/{id}/schedule` | Расписание зала на день / неделю              |
| GET   | `/api/resources/{id}/reviews`  | Отзывы и средний рейтинг                      |

### Требуют авторизации `Bearer {token}`

| Метод  | URL                           | Описание              |
| ------ | ----------------------------- | --------------------- |
| POST   | `/api/auth/login`             | Логин, получить токен |
| POST   | `/api/auth/logout`            | Выход                 |
| GET    | `/api/auth/me`                | Текущий пользователь  |
| GET    | `/api/bookings`               | Мои бронирования      |
| POST   | `/api/bookings`               | Создать бронирование  |
| DELETE | `/api/bookings/{id}`          | Отменить бронирование |
| POST   | `/api/resources/{id}/reviews` | Оставить отзыв        |

## Query-параметры GET /api/resources

| Параметр     | Пример           | Описание                                             |
| ------------ | ---------------- | ---------------------------------------------------- |
| `per_page`   | `5`              | Кол-во записей на странице (макс. 50)                |
| `type`       | `gym`            | Фильтр по типу зала                                  |
| `capacity`   | `10`             | Минимальная вместимость                              |
| `max_price`  | `500`            | Максимальная цена за час                             |
| `date`       | `2026-03-20`     | Поиск свободных (вместе с `start_time` и `end_time`) |
| `start_time` | `13:00`          | Время начала                                         |
| `end_time`   | `15:00`          | Время окончания                                      |
| `sort_by`    | `price_per_hour` | Поле сортировки                                      |
| `sort_dir`   | `asc` / `desc`   | Направление сортировки                               |

**Пример запроса — свободные залы:**

```
GET /api/resources?date=2026-03-20&start_time=13:00&end_time=15:00
```

**Пример запроса — фильтр + сортировка:**

```
GET /api/resources?type=gym&max_price=500&sort_by=price_per_hour&sort_dir=asc
```

## Query-параметры GET /api/resources/{id}/schedule

| Параметр | Пример         | Описание                    |
| -------- | -------------- | --------------------------- |
| `date`   | `2026-03-13`   | Дата (обязательно)          |
| `period` | `day` / `week` | Период (по умолчанию `day`) |

**Пример ответа:**

```json
{
  "resource": "Зал силовой",
  "period": "day",
  "from": "2026-03-13",
  "to": "2026-03-13",
  "schedule": [
    {
      "date": "2026-03-13",
      "start_time": "10:00",
      "end_time": "12:00",
      "booked_by": "Ivan"
    }
  ]
}
```

---

## Тело запроса POST /api/resources/{id}/reviews

```json
{
  "booking_id": 7,
  "rating": 5,
  "comment": "Отличный зал!"
}
```

**Правила:**

- Бронирование должно принадлежать текущему пользователю
- Дата + время окончания бронирования должны быть в прошлом
- Нельзя оставить два отзыва на одно бронирование
