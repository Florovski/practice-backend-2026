## Бизнес-правила

### 1. Создание бронирования

Валидация входных данных:

- `resource_id` — зал должен существовать в БД
- `date` — дата не раньше сегодня
- `start_time` / `end_time` — формат `HH:MM`, конец позже начала

### 2. Проверка пересечений по времени

Два интервала пересекаются если:

- начало нового < конец существующего **И**
- конец нового > начало существующего

```php
$conflict = Booking::where('resource_id', $request->resource_id)
    ->where('date', $request->date)
    ->where('status', 'active')
    ->where(function ($query) use ($request) {
        $query->where('start_time', '<', $request->end_time)
              ->where('end_time', '>', $request->start_time);
    })
    ->first();
```

При конфликте возвращается `422` с описанием конфликтующего бронирования:

```json
{
  "message": "Этот зал уже забронирован на выбранное время.",
  "conflict": {
    "date": "2026-03-20",
    "start_time": "10:00",
    "end_time": "12:00"
  }
}
```

### 3. Правила отмены

| Ситуация                          | Результат |
| --------------------------------- | --------- |
| User отменяет своё бронирование   | `200` ✅  |
| User отменяет чужое бронирование  | `403` ❌  |
| Отмена уже отменённого            | `422` ❌  |
| Admin отменяет любое бронирование | `200` ✅  |

### 4. Доступ к списку бронирований

```php
if ($user->isAdmin()) {
    // Admin видит ВСЕ бронирования
    $bookings = Booking::with(['user', 'resource'])->get();
} else {
    // User видит ТОЛЬКО свои
    $bookings = Booking::with(['resource'])
        ->where('user_id', $user->id)
        ->get();
}
```

## Журналирование

Все бизнес-операции логируются в `storage/logs/laravel.log`:

| Событие                | Уровень   | Данные                                        |
| ---------------------- | --------- | --------------------------------------------- |
| Бронирование создано   | `info`    | booking_id, user_id, resource_id, дата, время |
| Конфликт времени       | `warning` | user_id, resource_id, conflict_id, причина    |
| Бронирование отменено  | `info`    | booking_id, initiator_id, is_admin            |
| Попытка отменить чужое | `warning` | initiator_id, booking_id, owner_id, причина   |
