# Gym Booking API

## Описание проекта

REST API для системы бронирования ресурсов спортзала.
Пользователи могут просматривать доступные залы и бронировать их на определённое время.
Администратор управляет залами и имеет доступ ко всем бронированиям.

**Предметная область:** Спортзал (Gym)  
**Стек:** PHP 8.x, Laravel 11, MySQL  
**Аутентификация:** JWT (tymon/jwt-auth)

## Список эндпоинтов API

### Аутентификация

| Метод | URL                  | Кто может   | Описание                        |
| ----- | -------------------- | ----------- | ------------------------------- |
| POST  | `/api/auth/register` | Все         | Регистрация нового пользователя |
| POST  | `/api/auth/login`    | Все         | Вход и получение JWT-токена     |
| POST  | `/api/auth/logout`   | Авторизован | Выход из системы                |
| GET   | `/api/auth/me`       | Авторизован | Данные текущего пользователя    |

### Ресурсы (залы)

| Метод  | URL                   | Кто может    | Описание                     |
| ------ | --------------------- | ------------ | ---------------------------- |
| GET    | `/api/resources`      | Авторизован  | Список всех активных залов   |
| GET    | `/api/resources/{id}` | Авторизован  | Информация о конкретном зале |
| POST   | `/api/resources`      | Только admin | Создать новый зал            |
| PUT    | `/api/resources/{id}` | Только admin | Редактировать зал            |
| DELETE | `/api/resources/{id}` | Только admin | Удалить зал                  |

### Бронирования

| Метод  | URL                  | Кто может   | Условия                           |
| ------ | -------------------- | ----------- | --------------------------------- |
| GET    | `/api/bookings`      | Авторизован | User видит свои, admin — все      |
| POST   | `/api/bookings`      | Авторизован | Создать бронирование              |
| DELETE | `/api/bookings/{id}` | Авторизован | User — только своё, admin — любое |

### Расписание и отзывы

| Метод | URL                            | Кто может   | Описание        |
| ----- | ------------------------------ | ----------- | --------------- |
| GET   | `/api/resources/{id}/schedule` | Все         | Расписание зала |
| GET   | `/api/resources/{id}/reviews`  | Все         | Отзывы о зале   |
| POST  | `/api/resources/{id}/reviews`  | Авторизован | Оставить отзыв  |

## Запуск проекта

### Требования

- PHP >= 8.2
- Composer
- MySQL

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Florovski/practice-backend-2026.git
cd practice-backend-2026

# 2. Установить зависимости
composer install

# 3. Скопировать .env
cp .env.example .env

# 4. Сгенерировать ключ приложения
php artisan key:generate

# 5. Настроить .env — прописать данные БД
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=gym_booking
DB_USERNAME=root
DB_PASSWORD=

# 6. Сгенерировать JWT-секрет
php artisan jwt:secret

# 7. Создать таблицы и заполнить тестовыми данными
php artisan migrate:fresh --seed

# 8. Запустить сервер
php artisan serve
```
